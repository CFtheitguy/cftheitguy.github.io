Install the Printer & Scanner Driver

Install this on your computer so you can print to the Brother copier and scan documents back to your PC. Scanning will not work until this is installed.

Download the Printer Driver

Step 1 — Install the driver

  1. Make sure your computer is on the same Wi-Fi / network as the copier.
  2. Click the green Download the Printer Driver button above.
  3. Open the downloaded file (Y22C_C1_ULWL_PP-inst-G1.EXE) — usually in your Downloads folder or at the bottom of your browser.
  4. Click Yes if Windows asks “Do you want to allow this app to make changes?”
  5. Accept the license agreement and click Next.
  6. When asked how the printer is connected, choose Wireless Network Connection (or Wired / USB if a cable is plugged in).
  7. Pick your Brother printer from the list it finds, then click Next and let it finish. Restart the computer if it asks.

Step 2 — How to scan

  1. Put the pages face-down on the glass, or face-up in the top feeder.
  2. Click the Windows Start button, type Brother iPrint&Scan, and open it.
  3. Make sure your printer is shown at the bottom left. If not, click Select your Machine and pick it.
  4. Click Scan. Choose PDF for documents or JPEG for photos.
  5. Click Scan again — the pages go through and appear on screen.
  6. Click Save and choose where to put the file (for example your Documents folder or the Desktop).

Windows only · Printer must be on and on the same network · Takes about 5 minutes

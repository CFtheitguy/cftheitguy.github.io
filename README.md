# cftheitguy.github.io

- `docs/ivr-script.md` — Friendly, professional phone IVR greeting and after-hours script.
- `desktop/` — **linearOS**, the support desktop (linearit.co/desktop). A Windows-11-style desktop that runs in the browser: draggable windows, taskbar, start menu, right-click menu, a UAC-style prompt and five switchable wallpapers. Doubles as a support portal — ticket wizard, remote-assist instructions, billing, toolbox and contact. One self-contained HTML file, no backend; the ticket wizard is a front-end demo and says so on screen.
- `pdf/` — **Linear PDF**, a free PDF toolkit (linearit.co/pdf). **Edit** (retype the text already on the page, plus type, draw, highlight and white things out — `pdf/edit.js`), plus combine, organise (rotate/delete pages), split, shrink, images→PDF, PDF→images and watermark — the jobs people otherwise buy Acrobat for. Everything runs in the browser: pdf-lib and pdf.js are vendored in `pdf/vendor/` rather than loaded from a CDN, and the page's CSP names no remote host, so a customer's document cannot leave their machine. No backend, no account. Edits are stored in PDF user space via pdf.js's `convertToPdfPoint`, so they land exactly where clicked at any zoom, on high-DPI screens and on pages carrying a `/Rotate`. Text is folded to WinAnsi (curly quotes, dashes, ellipses) because the standard PDF fonts can't encode more; anything left over is dropped with a warning rather than failing the save. The Move tool works on the page's own text as well as on what the user added: dragging a run materialises it into an edit in place, so nothing is written to the document until a drag actually starts. Retyping detects each text run with pdf.js, samples its real ink and background colour off the rendered pixels, covers the original and redraws in the closest standard font (matched from the font name pdf.js reports). It works this way because a PDF's own fonts are usually subset — they embed only the glyphs already used — so newly typed letters would have no glyph. **A covered run is hidden, not deleted: the original text stays extractable.** The editor says so on screen and offers a flattened save (pages re-rendered as images) for when that matters — verified to leave an empty text layer. Password-protected PDFs can't be opened (pdf-lib can't decrypt) and the tool says so plainly.
- `photos/` — **Linear Photos**, a Photoshop-style photo editor (linearit.co/photos). Layers with blend modes and opacity, brush/eraser (pen pressure), marquee, lasso and magic-wand selections that add, subtract, intersect, invert and feather, clone stamp, paint bucket, gradient, editable text layers, shapes, crop, free transform (scale/rotate), and adjustments and filters (levels, hue/saturation, exposure, colour balance, black & white, blur, unsharp mask, noise, pixelate, vignette). Every edit renders a new layer canvas rather than drawing in place, so history steps share the canvases of layers they didn't touch. Selections are alpha masks, and all painting goes through one masked-merge path (`editedCanvas` in `photos/app.js`). No libraries, no backend: the page's CSP names no remote host, so a photo can't leave the machine. Images over 16 MP are scaled down on open, because that's iOS Safari's canvas ceiling.
- `video/` — **Linear Video**, a video editor (linearit.co/video). Multi-track timeline (video/overlay tracks and audio tracks) with drag-to-move, edge trimming, split, ripple delete, duplicate and snapping; titles (fonts, outline/box/shadow, rise/pop/typewriter animations) and colour cards; per-clip speed, volume, fades, fit/fill, position, scale, rotation, mirror, slow zoom, brightness/contrast/saturation/blur/black & white; detach audio; 16:9, 9:16, 1:1, 4:5 and 4:3 frames. Nothing is re-encoded while editing: each clip owns a `<video>`/`<audio>` element kept in step with the playhead and the preview canvas composites whatever is under it. Export plays the project through once in real time into a MediaRecorder (canvas `captureStream()` plus a Web Audio mix), so it takes as long as the video and the tab must stay in front — the editor cancels and says so if it's hidden. MP4 where the browser can record it (Chrome, Edge, Safari), WebM otherwise; WebM output gets a Duration element patched into its header because MediaRecorder leaves it out. The project lives in the tab only (no save/reload). No libraries, no backend, and the page's CSP names no remote host.
- `drums/` — **Linear Drums**, a multi-touch drum kit for the iPad (linearit.co/drums). Every sound is synthesised in the browser, so there are no samples to download; includes a metronome, seven grooves and a two-bar loop recorder.
- `noise/` — **Linear Noise**, a browser noise machine (linearit.co/noise). Twelve sounds — white/pink/brown noise, rain, thunder, wind, ocean, stream, campfire, crickets, fan and a drone — all synthesised live with the Web Audio API, so there are no audio files in the repo. Mixer, presets, sleep timer with fade-out, mixes saved to `localStorage` and shareable via URL hash. No backend.
- `race/` — **Linear Race**, a pylon air racing game (linearit.co/race). Six aircraft classes and three courses; round every pylon on the outside or take a two second penalty, win races to climb the ranks and unlock faster aircraft. Canvas and Web Audio only — no engine, no assets, no backend, and progress is kept in `localStorage`.
- `typing/` — **Linear Type**, a browser typing tutor (linearit.co/typing). 31 lessons, timed tests and weak-key drills; progress is kept in `localStorage`, with no account or backend.
- `time/` — **Linear Time**, an installable time-tracking PWA (time.linearit.co). Setup + rollout guide in [`time/README.md`](time/README.md); Cloudflare Worker + D1 backend in [`time-worker/`](time-worker/README.md).
- `board/` — **Linear Board**, a whiteboard two people can share with a link (board.linearit.co). No signup; boards delete themselves 24 hours after the last change. App notes in [`board/README.md`](board/README.md); Cloudflare Worker + Durable Object relay in [`board-worker/`](board-worker/README.md).
